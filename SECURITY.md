# Security Policy

## Supported Versions

This project is under active development. Security fixes are applied to the
latest version on the `main` branch.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities or
to report errors that may expose sensitive information.

Instead, report it privately by email:

**khaledhossain.not@gmail.com**

When reporting, please include as much of the following as you can:

- A description of the issue or error and its potential impact
- Steps to reproduce (or a proof of concept)
- Affected component (e.g. `server.py`, an agent tool, deployment config)
- Any relevant logs or error messages (with secrets redacted)

## What to Expect

- I'll acknowledge your report as soon as I can.
- I'll investigate and keep you updated on the progress.
- Once resolved, I'm happy to credit you for the disclosure if you'd like.

Thank you for helping keep novelsync-agents and its users safe.
